# Changelog

This file records notable public milestones for the project.

## 1.0.0-alpha.1 - 2026-09-26

The first classroom alpha provides complete beginner setup paths for Windows,
Ubuntu/Debian Linux, and macOS.

### Included

- terminal, files, folders, and command-line foundations,
- Git installation, configuration, and local repository practice,
- GitHub account, repository, first commit, and first push workflows,
- Visual Studio Code installation and integrated terminal workflows,
- `uv` installation and a first packaged Python project,
- completion checklists and platform-specific troubleshooting,
- classroom preflight, completion evidence, and an instructor pilot checklist,
- automated local Markdown link and YAML syntax checks,
- structured issue forms for student reports and feedback, and
- separate MIT and CC BY-SA 4.0 licensing scopes.

### Known limitations

- The material still needs feedback from a supervised classroom pilot.
- Focused screenshots are not yet available for the most visual steps.
- A dedicated accessibility review has not been completed.
- Automated checks validate local links but do not request external websites.

# Create a GitHub Account

GitHub is the website where you can store Git repositories online.

Before you can push your code to GitHub, you need a GitHub account.

## What you will learn

In this section, you will learn how to:

- create a personal GitHub account,
- choose a username,
- verify your email address,
- understand why two-factor authentication matters,
- find your GitHub profile.

## Before you start

You should already understand:

- what Git is,
- what GitHub is,
- what a repository is.

If not, read this section first:

- [What Are Git and GitHub?](../04_what_are_git_and_github.md)

## Step 1: Open GitHub

Open your web browser.

Go to:

```text
https://github.com/signup
```

This opens the GitHub sign-up page.

## Step 2: Create your account

Follow the prompts on the GitHub sign-up page.

GitHub will ask for information such as:

- your email address,
- a password,
- a username.

Your username will be visible in repository URLs.

For example, if your username is `alex-dev`, your repositories may use URLs like:

```text
https://github.com/alex-dev/my-project
```

Choose a username that you are comfortable using for learning and coding.

## Step 3: Verify your email address

After signing up, GitHub may ask you to verify your email address.

Open your email inbox and look for a message from GitHub.

Follow the verification link or enter the verification code if GitHub asks for one.

Email verification is important because some GitHub features may not work until your email address is verified.

## Step 4: Save your sign-in information safely

Use a strong password.

Do not store your password inside a project folder.

Do not write your password in a file that you might later push to GitHub.

If you use a password manager, save your GitHub login there.

## Step 5: Set up two-factor authentication

Two-factor authentication is often shortened to:

```text
2FA
```

2FA adds an extra security step when signing in.

GitHub strongly recommends using 2FA to protect your account.

You do not need to understand every security detail right now, but you should follow GitHub's prompts if it asks you to configure 2FA.

## Step 6: Open your profile

After signing in, open your GitHub profile page.

One way is to go to this address and replace `YOUR-USERNAME` with your GitHub username:

```text
https://github.com/YOUR-USERNAME
```

Example:

```text
https://github.com/alex-dev
```

If the page opens, your account exists and you are signed in.

## Common problems

### I already have a GitHub account

That is fine.

Use your existing account.

Make sure you can sign in and access your profile.

### My username is already taken

GitHub usernames must be unique.

Try a simple variation, such as adding `dev`, `code`, or a short number.

Avoid usernames that reveal private information you do not want public.

### I did not receive the verification email

Check your spam or junk folder.

Also make sure you typed your email address correctly.

If needed, use GitHub's option to resend the verification email.

### GitHub asks me to choose a plan

For this beginner guide, a free personal account is enough.

You can change plans later if you need more features.

## Key idea

A GitHub account lets you store repositories online.

Before pushing code from your computer to GitHub, make sure you can sign in and open your profile.

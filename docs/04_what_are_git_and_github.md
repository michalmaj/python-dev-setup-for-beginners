# What Are Git and GitHub?

Before installing Git, it helps to understand what Git and GitHub are.

They are related, but they are not the same thing.

## What you will learn

In this section, you will learn:

- what Git is,
- what GitHub is,
- why Git and GitHub are different,
- what a repository is,
- what commits and pushes are.

## What is Git?

Git is a tool that tracks changes in files.

It is mostly used for programming projects, but the basic idea is simple:

```text
Git remembers how your project changes over time.
```

For example, if you edit a file today and break something tomorrow, Git can help you compare the changes.

Git works on your computer. You can use Git even without GitHub.

## What is GitHub?

GitHub is a website where Git repositories can be stored online.

In simple words:

```text
Git tracks your project.
GitHub stores a copy of your project online.
```

GitHub is useful because it lets you:

- back up your code,
- share your code,
- collaborate with other people,
- review changes before they are merged.

## What is a repository?

A repository is a project folder tracked by Git.

You may also see the shorter word:

```text
repo
```

For beginners, you can think of a repository as:

```text
a project folder with change history
```

## What is a commit?

A commit is a saved point in your project history.

It records what changed at a specific moment.

A good commit has a short message that explains the change.

Example:

```text
docs: add Git installation guide
```

You will learn how to make commits later in this guide.

## What is a push?

A push sends your local Git commits to GitHub.

In simple words:

```text
commit = save a point in local history
push = send that history to GitHub
```

You can make commits on your computer before pushing them to GitHub.

## Common problems

### I thought Git and GitHub were the same thing

That is a common beginner mistake.

Git is the tool on your computer.

GitHub is the website where repositories can live online.

### Do I need GitHub to use Git?

No.

Git can track a project locally on your computer.

GitHub becomes useful when you want to back up, share, or collaborate on a project.

### Do I need Git before GitHub?

For this guide, yes.

You will install and configure Git first. Later, you will create or connect a GitHub account.

## Key idea

Git tracks changes in a project folder.

GitHub stores Git repositories online.

They work together, but they are different tools.

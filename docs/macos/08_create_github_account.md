# Create a GitHub Account

GitHub is a website where you can store Git repositories online.

## What you will learn

You will learn how to:

- create a personal GitHub account,
- choose a public username,
- verify your email address,
- protect the account with two-factor authentication.

## Before you start

Make sure you understand the difference between Git and GitHub:

- [What Are Git and GitHub?](../04_what_are_git_and_github.md)

## Step 1: Open GitHub

Open a web browser and go to:

```text
https://github.com/signup
```

## Step 2: Create the account

Follow the sign-up prompts. GitHub will ask for an email address, password, and username.

Your username becomes part of public repository addresses. For example:

```text
https://github.com/alex-dev/my-project
```

Choose a name you are comfortable using for coding projects.

## Step 3: Verify your email address

Open the verification message sent by GitHub and follow its instructions.

Some features may remain unavailable until the email address is verified.

## Step 4: Protect your account

Use a strong, unique password and store it in a password manager if possible.

Never save passwords, recovery codes, or access tokens inside a project folder. A project may later become public.

Set up two-factor authentication when GitHub asks. It adds a second check when you sign in.

Store the recovery codes somewhere private and outside your project folders.

## Step 5: Check your profile

Sign in and replace `YOUR-USERNAME` in this address:

```text
https://github.com/YOUR-USERNAME
```

If your profile opens, the account is ready.

## Common problems

### The username is already taken

GitHub usernames are unique. Try a simple variation, but avoid private information you do not want to publish.

### The verification message did not arrive

Check the spam folder and confirm that the email address is correct. GitHub also provides an option to resend the message.

### GitHub asks for a plan

A free personal account is enough for this guide.

# macOS Path

This learning path is for people using macOS.

It explains how to set up a beginner-friendly Python development environment on a Mac, from opening Terminal to pushing a first project to GitHub.

## Before you start

Read these shared introductions first:

- [What Is a Terminal?](../01_what_is_a_terminal.md)
- [Files, Folders, and Paths](../02_files_folders_and_paths.md)
- [Basic Terminal Commands](../03_basic_terminal_commands.md)
- [What Are Git and GitHub?](../04_what_are_git_and_github.md)

## What you need

You need:

- a Mac with a supported version of macOS,
- access to your macOS user account,
- an internet connection,
- permission to install applications.

Some installation steps may ask for your macOS account password.

## Recommended order

Follow the macOS path in this order:

1. Open Terminal
2. Learn basic shell commands
3. Create a projects folder
4. Install Homebrew
5. Install Git
6. Configure Git
7. Create a local Git repository

10. Connect Git with GitHub
11. Install Visual Studio Code
12. Open a project in VS Code
13. Open the VS Code terminal
14. Install `uv`
15. Create the first Python project
16. Make the first project commit
17. Check your completed setup
18. Troubleshoot common problems

## Terminal and shell

Terminal is the application where you type commands.

The shell is the program inside Terminal that reads those commands. Modern versions of macOS use a shell named Zsh by default.

The examples in this guide work in Zsh and use `bash` labels because they are Unix-like shell commands.

## Recommended project location

This guide keeps programming projects in:

```text
/Users/yourname/Projects
```

The shorter form is:

```text
~/Projects
```

Avoid spaces in beginner project names. Prefer `my-first-project` instead of `My First Project`.

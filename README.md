A beginner-friendly guide to setting up a modern Python development environment from zero.

This repository is for people who are new to programming tools and want to learn how to:

- open and use a terminal,
- understand basic command-line commands,
- install package managers such as Chocolatey, Homebrew, or Linux package managers,
- install Git,
- create and configure a GitHub account,
- connect Git with GitHub,
- install Visual Studio Code,
- create a Python project with `uv`,
- open and run the project in VS Code.

## Status

The first complete Windows, Linux, and macOS learning paths are available. The
`v1.0.0-alpha.1` milestone is ready for supervised classroom testing. See the
[changelog](CHANGELOG.md) for its scope and known limitations.

## Start here

If you are completely new to developer tools, start with:

- [Start Here](docs/00_start_here.md)
- [Check Your Computer Before You Start](docs/00_before_you_start.md)

This guide intentionally starts before Python itself. It first explains terminals, folders, command-line basics, Git, GitHub, VS Code, and only then moves to creating a Python project with `uv`.
